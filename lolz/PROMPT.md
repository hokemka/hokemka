Сделай оформление темы для форума lolz.live под мой проект в стиле liquid glass (стекло как в iOS 26).

ПРОЕКТ
- Название / ник: <НАЗВАНИЕ>
- Чем занимаемся (одной фразой): <ОПИСАНИЕ>
- Услуги / товары: <СПИСОК>
- Преимущества (3–4 коротких пункта): <СПИСОК>
- Ссылки для кнопок: <ТГ, КАНАЛ, САЙТ, ОТЗЫВЫ>
- Аватарка / логотип: прикладываю файл. Цвета фона бери с неё.

ОРИЕНТИР
За основу бери репозиторий hokemka/hokemka, папку banner/ — там готовый Remotion-проект (React):
стеклянные плитки с иконками технологий, которые плавают и преломляют фон, стеклянные карточки и
пилюли, блик, градиент фона под цвет аватарки. Повтори этот стиль, поменяй контент и цвета.

ЧТО НУЖНО НА ВЫХОДЕ
1. Remotion-проект, который рендерит тему одним длинным полотном 1200px шириной,
   зацикленная анимация 6 секунд, 30 fps.
2. Скрипт, который режет полотно на горизонтальные куски и кодирует в GIF шириной 800px
   (15 fps, ffmpeg palettegen без дизеринга + gifsicle -O3 --lossy=60), прозрачные углы
   заливает цветом форума #111615.
3. Ряды с кнопками режет пополам (левая и правая кнопка — отдельные GIF), чтобы каждую
   можно было обернуть в свою ссылку.
4. Готовый BB-код для вставки: [CENTER], каждый кусок на своей строке без пустых строк,
   кнопки как [URL='ссылка'][IMG]...[/IMG][/URL], между двумя кнопками в ряду один пробел.
5. Скрины-превью, как это будет выглядеть на тёмном фоне форума, на ПК и на телефоне.

ОГРАНИЧЕНИЯ ФОРУМА (важно, проверено)
- HTML и CSS в обычной теме не работают: [html] только показывает код текстом.
  Поэтому весь дизайн — это GIF-картинки, а интерактив — только ссылки на картинках.
- Эффекты при наведении и нажатии сделать нельзя.
- Форум сам скругляет углы у каждой картинки, поэтому стыки кусков видны.
  Делай так, чтобы каждый кусок выглядел аккуратной отдельной карточкой.
- Доступные BB-коды: [CENTER], [URL], [IMG], [IMG=align=left], [spoiler=Название;align=center],
  [SIZE], [COLOR], [B], смайлик :tg: (значок телеграма).
- Картинки лучше загружать на CDN форума (nztcdn.com) через кнопку картинки в редакторе.
  Держи каждую GIF до ~3–4 МБ, всего на тему до ~12 МБ.

СТИЛЬ
- Шрифт заголовков Unbounded 700, текст Manrope / системный. Весь текст строчными,
  кроме названий брендов.
- Иконки технологий — настоящие (simple-icons), для Telegram — нормальный бумажный самолётик.
- Стекло только на плавающих элементах, мягкие тени, блик проходит по кнопкам раз в цикл.

Если у закреплённой темы будет кастомный дизайн от форума: отдельно сделай чистую
HTML+CSS версию без JS, без внешних скриптов, все классы с уникальным префиксом,
картинки только по ссылкам с CDN форума.
